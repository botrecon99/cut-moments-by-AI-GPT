======================================================================
HƯỚNG DẪN CHẠY TỪNG FILE - DEEPSEEK YOUTUBE PIPELINE FAST REPAIR
======================================================================

MỤC TIÊU:
- Nối tiếp dữ liệu project ChatGPT cũ.
- Dùng nhiều profile DeepSeek.
- Mỗi video tạo chat mới.
- Bật DeepThink trước khi phân tích.
- Upload transcript TXT.
- Lọc block kết quả cuối trước DONE.
- Tự sửa timestamp lệch nhỏ bằng Python, không bắt DeepSeek phân tích lại.
- Download MP3 + cắt/ghép bằng media worker.
- Chỉ ghi DONE khi file MP3 cuối hợp lệ.

======================================================================
A. THỨ TỰ CHẠY LẦN ĐẦU TIÊN
======================================================================

BƯỚC 0 - GIẢI NÉN PROJECT
-------------------------
Giải nén toàn bộ project vào 1 thư mục riêng.

Ví dụ:
E:\DEEPSEEK_YOUTUBE_PIPELINE_FAST_REPAIR\


BƯỚC 1 - CÀI THƯ VIỆN PYTHON
-----------------------------
Mở CMD trong thư mục project rồi chạy:

    pip install -r requirements.txt

Nếu máy đã cài đủ thư viện thì không cần chạy lại.

Ngoài ra máy cần có:
- Google Chrome
- ffmpeg
- ffprobe
- yt-dlp
- Node.js hoặc Deno

Pipeline hiện tại ưu tiên:
    python -m yt_dlp


BƯỚC 2 - NỐI DATA PROJECT CŨ
----------------------------
CHỈ CẦN LÀM 1 LẦN.

Chạy:

    CONNECT_OLD_WORKSPACE.bat

Sau đó dán đường dẫn THƯ MỤC project ChatGPT cũ.

Ví dụ:

    E:\audio chúa\story_pipeline_bundle\God Miracles Today 1111\cut-moments-by-AI-GPT

Nhấn ENTER.

Nếu thành công nó sẽ tạo:

    workspace_bridge.json

Từ lúc này project DeepSeek mới sẽ dùng trực tiếp DATA cũ:
- list.txt
- doneLink.txt
- failedLink.jsonl
- channels\
- transcripts
- ai_results
- MP3 đã làm
- raw_audio đang dở
- YouTube Chrome profile

KHÔNG cần copy đống data cũ sang folder DeepSeek mới.

QUAN TRỌNG:
Không chạy pipeline ChatGPT cũ và pipeline DeepSeek mới cùng lúc,
vì chúng dùng chung dữ liệu.


BƯỚC 3 - LOGIN DEEPSEEK PROFILE 1
---------------------------------
Chạy:

    LOGIN_DEEPSEEK_PROFILE.bat

Khi console hỏi chọn profile:

    1

Nhấn ENTER.

Chrome DeepSeek sẽ mở đúng profile:

    chrome_profiles\deepseek_accounts\deepseek1\Default

Đăng nhập bằng tay.

Chờ đến khi:
- URL không còn /sign_in
- đã nhìn thấy ô "Message DeepSeek"

Sau đó ĐÓNG cửa sổ Chrome DeepSeek đó.


BƯỚC 4 - LOGIN DEEPSEEK PROFILE 2
---------------------------------
Chạy lại:

    LOGIN_DEEPSEEK_PROFILE.bat

Chọn:

    2

Login deepseek2.

Chờ thấy ô "Message DeepSeek".

Sau đó ĐÓNG Chrome.

Nếu sau này có thêm deepseek3, deepseek4...
thì thêm account vào deepseek_accounts.json rồi login tương tự.


BƯỚC 5 - KIỂM TRA PATH PROFILE (TÙY CHỌN)
-----------------------------------------
Có thể chạy:

    python CHECK_DEEPSEEK_PROFILE_PATHS.py

Nó chỉ in đường dẫn profile DeepSeek mà main code sẽ dùng.

Ví dụ:

    deepseek1:
      ...\chrome_profiles\deepseek_accounts\deepseek1\Default

    deepseek2:
      ...\chrome_profiles\deepseek_accounts\deepseek2\Default

Nếu path đúng thì không cần làm gì thêm.


BƯỚC 6 - CHẠY PIPELINE THẬT
---------------------------
Chạy:

    python auto_youtube_deepseek_cut.py

Hoặc double-click file .py nếu Windows của mày đã gán Python đúng.

Khi hỏi:

    Dán 1 link YouTube rồi ENTER,
    hoặc chỉ ENTER để dùng list.txt:

Nếu muốn chạy toàn bộ list cũ:
    CHỈ NHẤN ENTER.

Nếu muốn chạy đúng 1 link:
    Dán link YouTube rồi ENTER.

======================================================================
D. CƠ CHẾ RESUME - CODE BỊ TẮT GIỮA CHỪNG THÌ SAO?
======================================================================

1) Link đã DONE
----------------
Nếu có trong:

    doneLink.txt

=> lần sau bỏ qua.


2) MP3 đã làm xong nhưng chưa kịp ghi DONE
------------------------------------------
Main scan file:

    * [VIDEO_ID].mp3

Nếu thấy final hợp lệ:
=> tự ghi DONE.


3) DeepSeek đã phân tích xong nhưng media chưa chạy xong
--------------------------------------------------------
Nếu đã có:

    <VIDEO_ID>_CUTS.txt

và kết quả còn hợp lệ:

=> REUSE AI result
=> không hỏi DeepSeek lại
=> đi thẳng download/cut.


4) raw_audio đang dở / đã tải xong
----------------------------------
Nếu:

    downloads\raw_audio.mp3

và:

    downloads\raw_audio_source.txt

đúng URL hiện tại,
ffprobe đọc được duration:

=> reuse raw audio
=> không tải lại.


5) Link FAIL
------------
failedLink.jsonl là lịch sử fail.

Pipeline tính:

    FAILED - DONE

=> những link fail chưa hoàn tất sẽ được retry ở cuối batch.


======================================================================
E. FLOW THỰC TẾ 1 VIDEO
======================================================================

VIDEO N:

    YouTube
      ↓
    lấy transcript timestamp
      ↓
    DeepSeek profile theo round-robin
      ↓
    New Chat
      ↓
    bật DeepThink
      ↓
    dán prompt
      ↓
    upload transcript TXT
      ↓
    Send
      ↓
    DeepThink reasoning
      ↓
    lấy FINAL RESULT cuối trước DONE
      ↓
    validate timestamp

Nếu timestamp lệch nhỏ:
      ↓
    Python FAST REPAIR
    KHÔNG gọi DeepSeek lại

Nếu không sửa local an toàn:
      ↓
    MICRO REPAIR
    chỉ gửi final block + vài dòng transcript gần timestamp sai

Sau đó:
      ↓
    MEDIA QUEUE
      ↓
    yt-dlp audio
      ↓
    FFmpeg cut/merge
      ↓
    verify MP3
      ↓
    doneLink.txt


Đồng thời:

VIDEO N+1 có thể bắt đầu DeepSeek
trong khi MEDIA của VIDEO N đang chạy.
